# POWER-BI-DASHBOARD-Consumer-Shopping-Behavior-Insights

### **Project Overview**
This project demonstrate consume shopping behavior by collecting survey data. The objective is to analysis pattern consumer shopping behavior.

### **Objective**
The dashboard was developed to answer key business questions:
+ Respondant profile, eg: age, gender, monthly income, occupation and country region.
+ Shopping behavior: Shopping mode, Online shopping frequency, Preferred platform, device used, spending category
+ Spending behavior : Average Monthly spend, BNPL usage, Payment method, Spending Category 

### **Setup**
This project uses Microsoft Power BI to analyze a dataset based on a survey of shopping behavior. The data was cleaned and prepared using Power Query to ensure consistency and accuracy before conducting the analysis and creating visualizations in Power BI.

### **Clean The Data**
Some data entries contained missing information, while others contained incorrect information. As the affected data accounted for less than 5% of the total dataset, the identified entries were replaced with null values using the Replace Values function in Power Query.

### **DAX Function**
DAX Functions used : SELECTEDVALUE, COUNTROWS, CALCULATE, DIVIDE, NOT ISBLANK, SUMMARIZE, FILTER, TOPN, MAXX
